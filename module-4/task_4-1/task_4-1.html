1. Why is object-oriented development so important in programming?

    2. Object-oriented development is important because it organizes code into reusable, modular objects that model real-world entities, making programs easier to manage, extend, and maintain.

  2. In Task 1, we create a static object called "AccountType." Explain what this object is used for and how this type of object can help us in software development.

    3. The static AccountType object is used to define fixed categories of accounts (like "Saving" or "Credit") so we can refer to them consistently, reducing errors and making the code easier to read, maintain, and update.

  3. Discuss why we use encapsulation in classes. Why do we want to "hide" code within our class? Explain how we can create "private" and "public" members in a constructor function.

    4. We use encapsulation to hide internal details of a class, protecting data and controlling access; in a constructor, private members are created using let or # inside the class, while public members are assigned to this.

  4. Explain what happens when we use the "new" command in JavaScript.

    5. Using new creates a new object from a class or constructor, sets up its internal structure, and calls the constructor function to initialize its properties.
