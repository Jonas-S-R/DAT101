1. What is the difference between invoking and creating a function?

    2. Creating a function defines its code and behavior, while invoking (or calling) a function actually runs that code.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Semicolons (`;`) mark the end of a statement, while code blocks `{ ... }` group multiple statements together to run as a single unit, such as inside functions, loops, or conditionals.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. If a function doesn’t return a value, trying to store its result assigns **`undefined`** to the variable.

  4. How do we separate parameters from each other when creating a function?

    5. We separate parameters with **commas** inside the parentheses when defining a function.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. Parameter names in a function definition act as placeholders, and when the function is invoked, the arguments you pass are assigned to these names in order.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. A parameter is `undefined` when a function call omits it because no value is passed, so the placeholder has nothing assigned.

  7. Explain what happens when we use recursive functions.

    8. A recursive function calls itself repeatedly, breaking the problem into smaller parts until it reaches a base case to stop the recursion.
